Ready for research? Show setup instructions

Research needs a one-time setup. Follow the research section of GETTING_STARTED.md in the repository to install dependencies and configure Daytona and your model provider.

Then preview the prompts with your downloaded brief (adjust the path if needed):

python -m agent_runtime.research --brief ~/Downloads/event-brief.json --category energy --dry-run

For a live run, replace --dry-run with --output event-research-report.json, then import that file. Live research uses paid Daytona and model-provider services; dry run creates no sandboxes.

Choose Save event draft to keep your event on this computer. Keep downloaded reports so you can reopen them after closing this tab.
